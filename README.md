Je suis Pazuluda, développeur français passionné par l’administration système, l’automatisation, le backend, Android et l’infrastructure.

J’aime construire des outils complets plutôt que des démos isolées : comprendre un besoin réel, automatiser ce qui peut l’être, ajouter des garde-fous, tester, observer puis améliorer jusqu’à obtenir quelque chose de réellement utile.

Mes terrains de jeu principaux sont Windows, Linux, Active Directory, Hyper-V, les API, les applications Android et les services auto-hébergés.
